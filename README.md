# ぽちっとぬりえ

3歳ぐらいの子ども向け、iPad（横向き）で遊ぶぬりえアプリ。
ビルド不要・依存ライブラリ無しの静的サイトで、ホーム画面に追加するとオフラインでも起動します。

**→ https://jmv0725rubreadextribe-cpu.github.io/pochitto-nurie/**

## 画面

1. **タイトル** … 「タッチ」で次へ。BGMがここから流れはじめます
2. **えらぶ** … 36枚から1枚。左右のボタンで3ページを切り替え
   （◀ どうぶつ ／ のりもの ／ おはな ▶ · 各12枚）
3. **ぬりえ** … 細めのクレヨン／20色パレット（ひらがな）／けしごむ／
   ぜんぶけす／ほぞん／もどる／カラーのみほん

## しくみ

- イラストは `art.js` に SVG で1つずつ定義。`fill="#xxxxxx"` を白に置換したものが線画になる
- 線画は `mix-blend-mode: multiply` で最前面。はみ出して塗っても黒い線が消えず、
  図形の重なり（車輪と車体など）の隠れ線も正しく隠れる
- クレヨンは半透明の円を細かくずらして重ねることで、かすれた質感を出している
- けしごむは `destination-out` で塗った色だけを消す（線画は別レイヤーなので残る）
- 「ほぞん」は 白地 → 塗り → 線画(multiply) を1枚の canvas に合成して PNG 化。
  iPad では長おしで写真に保存する
- `sw.js` がアプリ一式をキャッシュし、オフラインでも起動できるようにする

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組みとスタイル |
| `app.js` | 画面の動き（描画・ページ切替・保存・BGM） |
| `art.js` | 36枚のイラストと20色のパレット |
| `haikei.svg` | タイトル画面の初期背景 |
| `yuseimagic-subset.woff2` | 見出し用フォント（使う文字だけに削ったもの） |
| `いつもの散歩道.mp3` | BGM |
| `sw.js` | オフライン用キャッシュ |

## 絵や色を増やす

`art.js` の `NORIMONO` / `DOUBUTSU` / `OHANA` に `{ id, name, svg }` を追加します。
座標は `viewBox="0 0 400 300"` 基準。`tire()` `petals()` `leaf()` などの部品が使えます。
色は `PALETTE` を編集（数を変えたら `index.html` の `.palette` の
`grid-template-columns:repeat(10,1fr)` も合わせる）。

**更新したら `sw.js` の `CACHE` のバージョンを上げてください。**
上げないと iPad が古い版を表示しつづけます。

## クレヨンの太さ

`app.js` の `const R = 12;` の数字。大きくすると太くなります。

## タイトル画面の背景

初期状態は `haikei.svg`。好きな写真に変えたいときは、タイトル画面の右上にある
歯車を **長おし** → 「がぞうを えらぶ」。選んだ画像はその端末の中だけに保存されます。
