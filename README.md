# ぽちっとぬりえ

3歳ぐらいの子ども向け、iPad（横向き）で遊ぶぬりえアプリ。
ビルド不要・依存ライブラリ無しの静的サイトで、ホーム画面に追加するとオフラインでも起動します。

## 画面

1. **タイトル** … 「タッチ」で次へ
2. **えらぶ** … 10枚のカラー画像から1枚
3. **ぬりえ** … 細めのクレヨン／10色パレット（ひらがな）／けしごむ／もどる／カラーのみほん

## しくみ

- イラストは `art.js` に SVG で1つずつ定義。`fill="#xxxxxx"` を白に置換したものが線画になる
- 線画は `mix-blend-mode: multiply` で最前面。はみ出して塗っても黒い線が消えず、
  図形の重なり（車輪と車体など）の隠れ線も正しく隠れる
- クレヨンは半透明の円を細かくずらして重ねることで、かすれた質感を出している
- けしごむは `destination-out` で塗った色だけを消す（線画は別レイヤーなので残る）
- `sw.js` がアプリ一式をキャッシュし、オフラインでも起動できるようにする

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 3画面のUIと描画処理 |
| `art.js` | 10枚のイラスト（SVG）と10色のパレット |
| `haikei.svg` | タイトル画面の初期背景 |
| `sw.js` | オフライン用キャッシュ |
| `manifest.webmanifest` | ホーム画面に追加したときの設定 |

## 絵や色を増やす

`art.js` の `ART` に `{ id, name, svg }` を追加します。座標は `viewBox="0 0 400 300"` 基準。
色は `PALETTE` を編集（数を変えたら `index.html` の `.palette` の
`grid-template-columns:repeat(10,1fr)` も合わせる）。

**更新したら `sw.js` の `CACHE` のバージョン（`v1`）を上げてください。**
上げないと iPad が古い版を表示しつづけます。

## タイトル画面の背景

初期状態は `haikei.svg`。好きな写真に変えたいときは、タイトル画面の右上にある
歯車を **長おし** → 「がぞうを えらぶ」。選んだ画像はその端末の中だけに保存されます。
